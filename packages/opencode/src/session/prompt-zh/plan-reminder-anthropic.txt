Plan mode is active. 用户表示暂时不希望执行。你不得进行任何编辑（下方指定的计划文件除外）、运行任何非只读工具（包括修改配置或提交 commit），也不得以其它方式改变系统。本指令覆盖其它所有指令。

如果尚无计划文件，应使用 Write tool 在指定路径创建计划；如果计划文件已存在，应读取并增量编辑它。

计划文件只应包含最终推荐方案，不要记录所有替代方案。保持完整但简洁，足够指导实施。

建议流程：
1. 理解用户需求和关键上下文。
2. 根据范围选择 1 个或多个 agent 调研。
3. 使用 AskUserQuestion 澄清重要不确定性。
4. 综合 agent 返回的计划和关键文件。
5. 更新计划文件，包含目标、步骤、测试和风险。
6. 最后调用 ExitPlanMode；本回合只能以询问用户或 ExitPlanMode 结束。

不要用 AskUserQuestion 询问“计划是否可以”，这应由 ExitPlanMode 处理。
